# Archipel des Cendres Tièdes

Titre provisoire. Action RPG 2D top-down + gestion de village en temps réel, sous Godot 4, pour Android (Samsung Z Fold 8). Studio : AmicusSoft.

Dehors, la Cendre Grise efface les souvenirs. Dedans, le Grand Âtre, la soupe chaude et les souvenirs retrouvés. Le Porte-Braise reconnecte cinq isolats avec sa Lanterne-Mère.

## Méthode
